# Registros de decisiones de arquitectura (ADR)

Una decisión técnica por archivo, con el nombre `NNNN-titulo-en-minusculas.md` (por ejemplo, `0001-stack.md`).

## Plantilla

```markdown
# NNNN — Título

- Estado: propuesta | aceptada | reemplazada por NNNN
- Fecha: AAAA-MM-DD

## Contexto
Qué problema o fuerza obliga a decidir.

## Decisión
Qué se decide.

## Alternativas consideradas
Opciones descartadas y por qué.

## Consecuencias
Qué se gana, qué se pierde y qué queda pendiente.
```

## Índice

| N.º | Título | Estado |
|---|---|---|
| — | (las primeras ADR se escriben en F2: 0001 stack, 0002 tiempo real, 0003 persistencia, 0004 registro de eventos, 0005 notas grupales) | — |
